# Loba Cartas — prototipo en Unity

Prototipo académico de una mesa de cartas desarrollado con Unity y C#. El proyecto explora la presentación de una baraja, el cambio entre el frente y el dorso de cada carta y una navegación básica entre menú y mesa.

## Qué incluye

- Una escena de menú y una escena de mesa.
- Un prefab reutilizable para representar cartas.
- Carga de sprites desde `Assets/Resources/baraja_completa.png` y creación de la baraja en la mesa.
- Control visual para mostrar el frente o el dorso de una carta.
- Recursos gráficos y sonidos usados por el prototipo.

## Estado

Es un prototipo en desarrollo. El repositorio muestra la base visual y de escenas; no implementa todavía una partida completa ni las reglas de Loba.

## Abrir el proyecto

1. Instala la versión de Unity indicada en `ProjectSettings/ProjectVersion.txt`.
2. Abre esta carpeta desde Unity Hub.
3. Inicia el proyecto desde la escena `Assets/Scenes/Menu.unity`.

El proyecto incluye los archivos fuente y recursos del juego. Se excluyeron la caché del editor, compilaciones y el APK generado.

## Tecnologías

`Unity` · `C#` · `Universal Render Pipeline` · `Unity Input System`
